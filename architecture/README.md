# Architecture Repository: template-vue-spa

Internal engineering documentation governing the lifecycle, evolution, and compliance of the `template-vue-spa` Copier template generator.

## Structure

* [`adr/`](adr/): Immutable Architectural Decision Records (MADR 3.0 format).
* [`designs/`](designs/): Software Design Documents (SDDs) detailing implementation mechanics.
* [`use-cases/`](use-cases/): Functional use cases for downstream generation scenarios.
* [`risk/`](risk/): Master Risk Register ($RE = P \times I$).
